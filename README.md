# HeroRush privacy policy

The public privacy policy for **HeroRush** (`com.mydatawave.herorush`), served by
GitHub Pages because Google Play and the App Store both require a reachable
privacy policy URL on the store listing.

This repository exists only to host that one page. The game's source lives
elsewhere and is not published here.

## Editing

`index.html` is the whole site — self-contained, no build step. Edit, commit,
push; Pages redeploys in under a minute.

The canonical copy lives in the game repository at `docs/privacy/index.html`.
**Change it there too**, or the two will drift and the page that players and
reviewers read will stop matching the code it describes.

## Before changing what it says

Play cross-checks this page against the Data Safety answers in Play Console, and
Apple against the App Privacy answers. A page that claims less collection than
the app performs is a rejection, and a live-listing policy violation.

So: if HeroRush ever attaches a real analytics or advertising provider — the
code has the interfaces but nothing wired to them — update this page *and* both
stores' disclosures *before* releasing that build.
